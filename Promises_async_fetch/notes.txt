1. Что такое Promise
    Promise (обещание) — это объект, который обещает вернуть результат позже.

    Состояния Promise:
    1. Pending — ожидание
    2. Resolved (Fulfilled) — выполнено
    3. Rejected — ошибка

    promise.then()
    promise.catch()

2. then() - Получаем результат после выполнения Promise.

3. catch() - ловим ошибки

4. async/await 
    await - Позволяет ждать результат Promise.

    async function test() {}
    const data = await promise;

5. try/catch - Для обработки ошибок.

6. Что такое fetch
    fetch делает HTTP-запросы к серверу. Сервер вернёт данные.

7. fetch + then

8. fetch + async/await

    const data = await response.json();
