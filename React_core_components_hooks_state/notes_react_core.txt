React — это JavaScript-библиотека для создания интерфейсов (UI).

*******************************************************
Без React:
html
<button id="btn">0</button>

JavaScript
const btn = document.getElementById("btn");
let count = 0;

btn.addEventListener("click", () => {
    count++;
    btn.textContent = count;
});

Мы сами ищем элементы через DOM и меняем их.
********************************************************
С React:
function App() {
    return <button>0</button>;
}

React сам обновляет интерфейс при изменении данных.

State

Как React понимает, что нужно обновить страницу?

React:
-> Меняет state.
-> Повторно вызывает компонент App().
-> Получает новый JSX.
-> Сравнивает старую и новую версию.
-> Обновляет только изменившиеся элементы.

Это называется: Re-render (повторный рендер компонента)

Важная идея
React работает по схеме: State → UI, а не UI → State
То есть интерфейс всегда строится из данных.

*******************************************************
Для объектов и массивов React очень удобно определять изменения 
через новую ссылку. Поэтому состояние в React обычно делают 
неизменяемым (immutable) и создают новые объекты/массивы вместо 
изменения старых.
