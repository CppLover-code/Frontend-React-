1. useEffect — это не хранение данных
Он не заменяет useState.
Он нужен для побочных эффектов (side effects) — действий, которые происходят после рендера.
Например:

* сохранить данные;
* загрузить данные;
* сделать HTTP-запрос;
* подписаться на WebSocket;
* запустить таймер.

2. localStorage
Хранит данные в браузере.
Переживает перезагрузку страницы.
Хранит только строки.
Для объектов и массивов используют:
JSON.stringify() — сохранить.
JSON.parse() — загрузить.

Ленивая инициализация (Lazy Initialization)
const [state] = useState(() => {
    ...
});

React выполнит функцию только один раз, при первом создании состояния.

Это удобно, когда начальное значение:

читается из localStorage;
вычисляется долго;
зависит от внешних данных.

Какую проблему решает React Router?

npm install react-router-dom

Без него:

вся логика страниц окажется в одном компоненте;
нельзя использовать URL как навигацию;
неудобно делиться ссылками;
после обновления страницы можно потерять текущую страницу.

С ним:

каждая страница — отдельный компонент;
URL определяет, что показать;
можно пользоваться кнопками "Назад" и "Вперёд" в браузере;
можно отправить ссылку другу, и он откроет сразу нужную страницу.
