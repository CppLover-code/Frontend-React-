1. useEffect — это не хранение данных
Он не заменяет useState.
Он нужен для побочных эффектов (side effects) — действий, которые происходят после рендера.
Например:

* сохранить данные;
* загрузить данные;
* сделать HTTP-запрос;
* подписаться на WebSocket;
* запустить таймер.

2. localStorage
Хранит данные в браузере.
Переживает перезагрузку страницы.
Хранит только строки.
Для объектов и массивов используют:
JSON.stringify() — сохранить.
JSON.parse() — загрузить.
